Repo Fleet Archive Backup
Overview · Terms

Privacy Policy

Last updated: 14 October 2026.

Current status: Public documentation only. The proposed automatic backup and associated production Google Drive OAuth data processing are not activated.

1. What this utility is for

Repo Fleet Archive Backup is an owner-operated research-evidence preservation utility being developed to copy and verify selected GitHub research artifacts into an owner-selected private Google My Drive location. It is not a public research platform, trading app, or consumer data collection service.

2. Google account access, if you opt in

The intended permission is https://www.googleapis.com/auth/drive.file. If activated after separate testing and owner consent, the tool would access only the Google Drive files and folders made available to it through this permission, including files it creates. This permission does not automatically grant access to every existing file or folder in Google Drive.

Google account authorization occurs on Google's own consent pages. This public documentation site does not request or collect Google account passwords or OAuth codes.

3. Research data and technical records

If activated, the tool is intended to process selected source research ZIP archives and evidence records from the owner's GitHub repositories, including run and artifact identities, timestamps, original content hashes, CRC/integrity checks and custody receipts. Some archived research may contain private material. The archive destination must remain private to the owner or explicitly authorized collaborators.

The information would be used solely to perform backup, integrity verification, replay/audit support and related owner-directed recovery. It would not be sold, used for advertising, or deliberately published on this website.

4. Storage and third parties

The proposed private archive location is the owner's Google My Drive; technical executions may run through owner-controlled GitHub Actions subject to separate approval. Google Drive and GitHub apply their own platform security, logging, privacy, and retention terms. No automated production transfer is enabled as of this policy's date. This public website is hosted by GitHub Pages and contains no custom analytics, sign-in form or tracking scripts, although the hosting service may process normal web-server request information under its own policies.

5. Credential protection and retention

Any future OAuth refresh token or client configuration would be stored only in an authorized secure credential store, not embedded in this public repository, a webpage, or a research receipt. The proposed tool must preserve original artifact identifiers and enforce verification before treating a backup as complete. Retention changes or deleting original GitHub evidence require a separate owner decision; this site grants no such authority.

6. Control and deletion

The owner may decline consent, revoke an authorization in their Google Account connections, or delete their own stored backup files through Google Drive. Revoking access prevents new API operations but does not automatically erase previously stored copies. Copies and technical audit history must be handled under the owner's retention and evidence-custody rules.

7. Changes and contact

This policy will be updated before activating any materially different processing, data sharing or permission scope. For a non-sensitive query about this documentation, use the public repository issue tracker. Do not include private research, credentials, OAuth codes, account numbers or personally sensitive information in public issues.
