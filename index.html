Repo Fleet Archive Backup

A proposed owner-controlled utility for preserving verifiable GitHub research evidence in a private Google My Drive folder.

Development / not activated

This informational site is public. The underlying research archive, GitHub evidence, owner credentials and Google Drive files are not hosted or accessible here.

這個網頁只提供工具說明及私隱政策，不會公開研究資料，也不會要求你在網站輸入 Google 密碼。

Purpose

The intended backup workflow would preserve original research ZIP evidence, run and artifact identities, cryptographic SHA-256 digests, and integrity receipts. Archived evidence is kept separate from live GitHub-native evidence.

Limited Google Drive access

The intended OAuth permission is https://www.googleapis.com/auth/drive.file. It is designed for files the user explicitly authorizes for the application or that the application creates. It is not a request for unrestricted Google Drive access.

Safety and governance

Production uploads have not been enabled. No GitHub artifact deletion, retention reduction, broker interaction, trading activity or financial account access is part of this website. Such operations require separate approval and validation.

Important: This is an informational page only. It contains no Google login form, API endpoints, analytics scripts or backup files. An OAuth grant, if introduced later, will use Google's own authorization screen.

Learn how the application would handle Google user data in the Privacy Policy, or review its Terms of Use. You can also review the public documentation source repository.
